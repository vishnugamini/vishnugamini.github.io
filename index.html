Brain

Shared memory for AI agents and assistants

Brain gives AI tools one place to find your project decisions, next steps, and preferences. A coding agent can save a handoff, and another assistant can pick up the work using the same notes, even if it runs on a different model.

Open Brain ↗
Agent workflows
Ask Brain uses the OpenAI Responses API to chain tool calls. It can find notes, cite the exact passages it used, and save a follow-up checklist when asked.
Indexing and retrieval
Brain splits notes into overlapping passages and indexes their embeddings in a per-user Pinecone namespace. Searches can stay within one project session, and matches are checked against the current note in PostgreSQL.
MCP and OAuth
A remote MCP server lets clients like ChatGPT and Claude search notes and open project sessions. OAuth connections are read-only by default. Users can grant write access to individual apps.
PostgreSQL storage
Supabase PostgreSQL stores notes and sessions with row-level security. Version checks prevent stale edits from overwriting newer ones, and idempotency keys prevent retries from applying the same edit twice.
